# 🎮 Dynamite

A web-based platformer where you control a mysterious stick of dynamite. Are you a hero or a villain? That's for you to decide as you navigate through increasingly challenging levels, trying to help bees survive their perilous journey.

## 🚀 Quick Start

1. Open `index.html` in your web browser
2. Press Space to start the game
3. No installation or server required - just pure gaming fun!

## 🎯 Gameplay

- Navigate through 5 increasingly challenging levels as a stick of dynamite
- Each level features more bees trying to make their way through
- Help bees survive by carefully managing your explosive presence
- Score points by successfully preventing bees from exploding

## 🎹 Controls

- **Left Arrow**: Move left
- **Right Arrow**: Move right
- **Up Arrow** or **Spacebar**: Jump
- **Spacebar**: Pause/Resume game
- **Click Pause Button**: Toggle pause state

## 🏆 Challenge Yourself

Can you reach the final level and achieve the highest score? Each level brings more bees to protect, with faster movements and shorter spawn intervals. How many bees can you help survive?
